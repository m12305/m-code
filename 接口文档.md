# m-code 刷题系统接口文档

## 概述

- **网关地址**: `http://localhost:8080`
- **认证方式**: JWT Bearer Token（Header: `Authorization: Bearer <token>`）
- **请求格式**: JSON (`Content-Type: application/json`)
- **统一响应格式**:

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

| code | 说明 |
|------|------|
| 200  | 成功 |
| 400  | 请求参数错误 |
| 401  | 未认证 / Token 无效 |
| 403  | 无操作权限 |
| 404  | 资源不存在 |
| 500  | 服务器内部错误 |

---

## 认证说明

除以下两个接口外，所有接口均需在 Header 中携带 JWT Token：

- `POST /api/user/login`
- `POST /api/user/register`

Gateway 验证 JWT 后向下游服务透传三个 Header：

| Header        | 说明     |
|---------------|----------|
| `X-User-Id`   | 用户 ID  |
| `X-Username`  | 用户名   |
| `X-User-Role` | 角色（0=普通用户, 1=管理员） |

# 三、判题模块 — `/api/judge`

## 3.1 提交代码判题

```
POST /api/judge/submit
```

**请求头**: `X-User-Id` (由 Gateway 自动注入)

**请求体**:

```json
{
  "questionId": 1,
  "answer": "用户的答案 / 代码",
  "language": 1
}
```

| 字段       | 类型    | 说明                                       |
|------------|---------|--------------------------------------------|
| questionId | Long    | 题目 ID                                    |
| answer     | String  | 用户答案（代码或选项）                     |
| language   | Integer | 编程语言：1=Java, 2=Python, 3=C++, 4=C, 5=JavaScript, 6=Go |

**响应**:

```json
{
  "code": 200,
  "data": {
    "id": 100,
    "userId": 1,
    "questionId": 1,
    "answer": "用户答案",
    "language": "JAVA",
    "status": "PENDING",
    "timeUsed": 0,
    "memoryUsed": 0,
    "createTime": "2025-01-01T00:00:00",
    "updateTime": "2025-01-01T00:00:00"
  }
}
```

| 字段       | 类型    | 说明                                                                                                    |
|------------|---------|---------------------------------------------------------------------------------------------------------|
| id         | Long    | 提交记录 ID                                                                                             |
| userId     | Long    | 用户 ID                                                                                                 |
| questionId | Long    | 题目 ID                                                                                                 |
| answer     | String  | 用户答案                                                                                                |
| language   | String  | 编程语言枚举名                                                                                          |
| status     | String  | 判题状态：`PENDING`(等待), `RUNNING`(判题中), `ACCEPTED`(通过), `WRONG_ANSWER`(错误), `COMPILE_ERROR`(编译错误), `RUNTIME_ERROR`(运行错误), `TIME_LIMIT_EXCEEDED`(超时), `MEMORY_LIMIT_EXCEEDED`(内存溢出) |

## 4.8 获取我的考试记录（含成绩刷新）

```
GET /api/exam/{examId}/my-record
```

**请求头**: `X-User-Id` (由 Gateway 自动注入)

| 路径参数 | 类型 | 说明    |
|----------|------|---------|
| examId   | Long | 考试 ID |

**说明**: 如果考试记录状态为 3（部分判题中）或 4（已提交），会自动调用判题服务刷新每道题的判题状态：
- 任意题目仍为 PENDING/RUNNING → 状态保持 3，不做分数更新
- 全部判题完成 → 汇总分数，状态更新为 2（已完成）

**响应**:

```json
{
  "code": 200,
  "data": {
    "id": 10,
    "examId": 1,
    "userId": 1,
    "totalScore": 80,
    "submitTime": "2025-06-01T10:30:00",
    "status": 2,
    "createTime": "2025-06-01T09:00:00",
    "updateTime": "2025-06-01T10:35:00"
  }
}
```

| 字段       | 类型          | 说明                                              |
|------------|---------------|---------------------------------------------------|
| id         | Long          | 考试记录 ID                                       |
| examId     | Long          | 考试 ID                                           |
| userId     | Long          | 用户 ID                                           |
| totalScore | Integer       | 总分（判题未完成时可能为中间值）                  |
| submitTime | LocalDateTime | 交卷时间                                          |
